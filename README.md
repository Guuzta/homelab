# 🏠💻 Homelab

Este repositório documenta a construção do meu homelab utilizando um notebook antigo como servidor.

## Objetivos

- Aprender Linux
- Aprender redes
- Aprender infraestrutura
- Praticar Docker
- Criar serviços self-hosted
- Desenvolver projetos para administração da rede

## Hardware

- Notebook: Lenovo IdeaPad S145-15IGM
- CPU: Intel Celeron N4000 1.10GHz
- RAM: 4GB
- SSD: KINGSTON SNV3S500GB

## Sistema Operacional

- Ubuntu Server LTS
